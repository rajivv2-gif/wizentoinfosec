# WIZENTO — Official Website (Plain HTML, CSS & Vanilla JS)

Enterprise Security, Technology & Growth Consulting website.

## Architecture
- **Pure Static Stack**: HTML5, Vanilla CSS3, Vanilla JavaScript (ES6+).
- **Zero Build Dependencies**: No Node.js, Webpack, or Vite required.
- **cPanel Compatible**: Works immediately with native cPanel Git™ Version Control via `.cpanel.yml`.

## File Structure
- `index.html` — Homepage with 60-Second Security Posture Assessment
- `services.html` — Services Overview & Interactive Scope Configurator
- `secure-assure.html` — Security Pillars & ISO 27001 / SOC 2 Scorecard
- `build-technology.html` — Cloud Modernization & Architecture
- `grow-intelligence.html` — Business Intelligence & Data Advisory
- `technology.html` — Vendor-Neutral Technology Radar & Redundancy Diagnostic
- `industries.html` — BFSI, Healthcare, SaaS, Supply Chain Blueprints
- `about.html` — Leadership, Governance & Fiduciary Charter
- `insights.html` — Executive Advisory Guides
- `contact.html` — Consultation Intake & Procurement FAQ Hub
- `terms.html` & `privacy.html` — Legal Charters
- `css/style.css` — Master design system and styling
- `js/main.js` — Core interactive engine (Section deep-links, accordions, modals, calculators)
- `.cpanel.yml` — Automated deployment task for cPanel
- `.htaccess` — Apache security headers, compression & clean URLs
